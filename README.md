# ThanhMienLand

Landing page mua bán, cho thuê nhà đất — bài thực hành HTML/CSS buổi 1 tại Cybersoft.

## Chạy dự án

1. Mở thư mục trong VS Code.
2. Chuột phải `index.html` → **Open with Live Server** (hoặc mở trực tiếp bằng trình duyệt).
3. Cần kết nối mạng để tải font, icon và ảnh.

## Cấu trúc

```
buoi1_bds/
├── .claude/CLAUDE.md   # Quy tắc & kiến trúc dự án
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   ├── img/
│   └── fonts/
├── docs/README.md      # Tài liệu chi tiết
├── index.html
└── README.md
```

Xem tài liệu đầy đủ tại [docs/README.md](docs/README.md).
